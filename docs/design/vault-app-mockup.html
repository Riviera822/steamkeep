What gets fetched

  • SteamID64 — the public account number Valve returns after sign-in.
  • Persona name — your public display name.
  • Avatar — your public profile picture.

All of it is public profile data, and this phone fetches it straight from Valve. It never travels through your cache server.

How can I verify this is legitimate?

The button sends you to https://steamcommunity.com — check the address bar before you type anything. If you are already signed in to Steam in that browser, all you do there is press Sign In; there is nothing else to fill in. SteamHangar never receives your username or password. Valve hands back only your SteamID64, and there is no code path in this app or on the server that accepts Steam credentials at all (ADR-0004).
