## What this run did NOT cover

- **SteamPrefill was never executed.** The binary's presence, checksum, ELF
  header and dynamic-library resolution inside the image were verified by
  inspection; running it needs a Steam session, which is the operator's
  one-time interactive step and deliberately never happens in a build or a
  test. A prefill job end-to-end through the container is the MVP test
  (Phase 1's last checkbox), not this package.
- **No LAN clients.** Every request came from the host, with an explicit
  `Host:` header standing in for a DNS-redirected Steam client — the same
  technique `core/tests/test-core.ps1` uses and for the same reason.
- **`vault-dns` was queried on 127.0.0.1:15353**, so this run proves the
  container's DNS behaviour, not a router/DHCP integration.
