# WP 1.9 container verification — 2026-08-05 21:42 UTC (post-review rebuild)

Recorded output of `deploy/tests/verify-stack.sh`. **62 checks, 0 failures.**

**This supersedes `VERIFICATION-20260805-204016.md`**, whose vault-api image
carried a blocker found by the second-stage review: the container user's home
directory was `/nonexistent`, and SteamPrefill creates a directory under `$HOME`
in a **static constructor** — so it died with a `TypeInitializationException`
before parsing any argument, on every invocation path, taking the documented
login flow and every prefill job with it. Fixed here (real HOME in both the
passwd entry and `ENV HOME`, backed by its own volume) and guarded by 11 new
checks, including a credential-free SteamPrefill smoke run on all three
invocation paths.
